# Missives

Stakeholder messages and shared documents for **Volunteer Committee Governance Tools**.

Use date-prefixed filenames (e.g. `2026-06-09-decision-topic.md`) so chronological order is easy to infer.

**Multiple versions should not exist** in this folder. A new revision replaces the live file, or the previous file moves to an archive subfolder (`archive/YYYY/` or `archive/YYYY-QN/`) so search is not split across competing copies.

Decisions, questions, discovery notes, sample references, mock-ups, feedback, and assets may all live here.
